# 2026-10-30 工作日志

## 并发优化批次（synth ①②③）落地

用户要求实现三项优化：① 并发视频生成；② 并发配音合成；③ 同场景 VO/视频
流水线重叠。全部写入 `avb/pipeline.py` 的 `synth()`：

- `synth()` 用 `ThreadPoolExecutor` 并发跑各场景 `video.generate()`（I/O 密集，
  厂商 GPU 在远端），`api_sem = Semaphore(max(1, min(workers,6)))` 限流防 429。
- 每个场景起 `vo_t = Thread(target=_run_vo)` 子线程跑 `_synth_vo`：script pin
  了 `scene.duration` 则先提交视频再 `vo_t.join()`（全重叠）；未 pin 则先 join
  取自然时长再定视频请求时长。Composer 只用 bg.png 海报帧，故两者时长可解耦。
- `account_halt = Event()`：account 级失败（余额/鉴权/配额）后 set，后续场景
  跳过 API 调用但已 in-flight 的让其完成，保留真实片段——替代旧串行
  "跳过第一个失败之后的全部"。
- 线程安全：`CostLedger.add` 加 `self._lock`；out/warn/cb 各用独立锁。

`avb/assets/video.py`：`_report` 改为走模块级 `report_progress()` + 线程局部
`_tls`，配 `progress_scope(cb)` 上下文管理器，解决并发时 progress 回调竞态。

`tests/test_concurrency.py`：3 个真实测试（fan-out 墙时、回调线程隔离、
account_halt 降级），顶部 `skipif(not _HEAVY_DEPS)` 让无 numpy/PIL 的 sandbox
自动 skip。
